# Stitch Prompts

These prompts are for visual exploration only. Stitch output is not final implementation authority, not governance authority, and not permission to add live APIs, external execution, deployment, publication, or public/client access.

## Prompt A - Visual Exploration

Create three visual directions for the Argument OS Control Center, a private/local operator dashboard.

Directions:

1. Dense operator console
2. Clean executive dashboard
3. Balanced daily operating cockpit

Each direction must include:

- Overview / Today dashboard
- Lane Summary
- Blockers
- Evidence / Archive
- Permission-gated action review

Product personality:

- calm, professional, operational, trustworthy, fast
- dense but readable
- task-oriented rather than decorative
- internal/private, not public/client-facing

Use this operating model:

```text
Monitor -> Triage -> Act -> Verify
```

Preserve these governance rules:

- UI visibility is not authority.
- Evidence is not doctrine.
- Dry-run is not activation.
- Permission-gated is not executed.
- Automations rationale is available.
- Freshness review is required only for current-truth promotion.
- Mock/static/generated/local data must not look like live external truth.
- Do not invent external execution, publication, deployment, workflow activation, messaging, financial execution, source mutation, or public access.

Use a layout with:

- left sidebar for primary areas
- top bar for mode/status/search/environment/context
- main canvas for current operating content
- right drawer for contextual details/actions/evidence
- toast/status layer for feedback

## Prompt B - IA Simplification

Simplify the Control Center information architecture around:

```text
Monitor -> Triage -> Act -> Verify
```

Recommended primary areas:

- Overview
- Today
- Lanes
- Blockers
- Evidence / Archive
- Permissions
- Settings

Map these current surfaces into the simplified IA without losing meaning:

- Today
- Products
- Theory / Doctrine
- Design / Territory
- Public Surfaces
- Creative / Peer Review
- Governance
- Background Tasks
- Archive / Evidence
- Evidence Details
- Daily Priority / Alert Cockpit
- Prepare Mode Action Queue
- Blocked Actions / Not-True Claims
- Permissioned command and command-gate panels
- Local/static/generated/API mode indicators

Make the interface easier to scan:

- show what matters today within 10 seconds
- separate active blockers from archive/evidence
- distinguish permission required from executed
- distinguish current truth from provenance-only evidence
- distinguish Automations rationale from freshness-reviewed truth
- label local/static/generated/live-read data clearly

Stitch output is visual exploration only. Do not treat it as final implementation authority.
